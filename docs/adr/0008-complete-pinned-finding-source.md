# ADR-0008：以完整固定源码呈现 Review 意见

## 状态

已接受。

## 背景

审查意见若只显示附近摘录，用户难以判断上下文。将意见覆盖到源码行上又会干扰阅读。

## 决策

Finding source API 返回该意见路径在该 Review 固定 base/head revision 的完整文件正文和高亮范围。前端在高亮首行之前渲染独立的 Review 注释卡片，不修改、遮挡或替换任何源码行。

## 后果

- 用户能在完整文件上下文中评估意见。
- 文件内容仍受任务固定 revision 和已验证 Finding 路径约束，不能读取原始工作区。
- 客户端必须让代码区域独立滚动，并在窄屏保持评论与源码内容换行或横向滚动，不允许页面横向溢出。
